## Repository Link

https://github.com/udaypratapsingh007

## Terminal Commands

```bash
git branch -M main
git remote add origin https://github.com/udaypratapsingh007
git push -u origin main
type nul > notes.txt
git add notes.txt
git commit -m "Add notes file"
git push
git log --oneline
```

## Explanation

- `git branch -M main` renames the current branch to main.
- `git remote add origin` connects the local repository to the GitHub repository.
- `git push -u origin main` uploads the commits to GitHub.
- `type nul > notes.txt` creates a new file.
- `git add`, `git commit` and `git push` upload the new file as another commit.
- `git log --oneline` shows the commit history.
